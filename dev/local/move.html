Connecting from an iPad

The hosted HTTPS trial needs a trusted HTTPS endpoint with streaming and CORS support. This workspace does not use plain HTTP endpoints from the hosted page. The local companion serves this same interface from your computer and reads Move’s existing mirror service. Open that local interface on your iPad, choose Move, enter the companion’s address and tap Connect. Nothing is installed on Move.

Download local companion · SHA256

On your Mac/computer: extract the download, open Terminal in move-companion, then run node start.mjs --help. Node.js 22 or later is required; no Git, build or npm install. The included README explains choosing your LAN address and opening the local page on iPad. This download is read-only. Local browser storage is separate from this hosted trial.

Session files

New session keeps a reopenable copy of your current work. Stop before saving. Clips, Scenes/Song, HarmonyBus, NuSaw, LFOs, mix, Movy layout and preferences are included. All workspace components share this browser session. Earlier Joint Play saves are available under Previous sessions; opening one preserves your current work. Move sessions stay on Move.

Audio & build

The real Movy UI, sequencer, HarmonyBus and Schwung chain host run in your browser. The enlarged display and control grid extend our HB/Movy browser interface. NuSaw supplies audio. Move OS, stock instruments, device master volume, master FX, external MIDI and Move Set files are not emulated. Hold a track and turn Volume to edit that track’s mix. Use Monitor level for browser output. The page currently needs a network connection to reload.
